# Zazen Designs — Homepage Redesign

Homepage redesign for [Zazen Designs](https://zazenwebdesign.com), styled after Wander.com's vacation-rental layout, with real Zazen agency content.

## Stack
Plain HTML/CSS/JS — no framework, no build step. Deployed to Vercel as a static site.

## Structure
- `index.html` — the full homepage
- `assets/` — image assets (project screenshots, etc.)
